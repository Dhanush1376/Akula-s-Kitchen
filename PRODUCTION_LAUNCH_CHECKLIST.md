# Akula's Kitchen — Production Launch Checklist

Status as of 2026-10-27. Status values:

- **PASS** — verified with the evidence noted.
- **FAIL** — verified broken.
- **NOT VERIFIED** — needs the action shown.
- **BLOCKED (external)** — needs the owner's account, device, approval or payment.

"Owner" means you (the account holder). "Code" means already done in the repository.

Launch rule: do **not** launch while any **P0** row is FAIL, NOT VERIFIED or BLOCKED.

## Rollback

- **Code:** Render → backend → Deploys → "Rollback" to the previous deploy. Vercel → Deployments → previous
  → "Promote to Production". No database migration in this release needs reverting. New collections
  (`twofactorpendings`, `whatsappnotifications`) and the optional `familyId` field are additive.
- **Region move (B9):** keep the old Render service running; revert the `vercel.json` rewrite targets.
- **Image migration (B3):** it only rewrites fields that still hold the exact old URL and keeps the local
  files; restore the previous values from the script's printed mapping if needed.
- **`REQUIRE_REDIS=true`:** if Redis fails, readiness returns 503 and Render keeps the old instance. Set
  `REQUIRE_REDIS=false` to recover, then fix Redis.
